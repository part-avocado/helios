See how much time you actually spend coding with AI.

teardrop reads the logs Claude Code and Codex already write, and a small plugin does the same for Amp. It adds up the time you were really there. No timers to start, nothing to keep running.

Works today with Claude Code, Codex (the CLI and the IDE extension), and Amp. VS Code with Copilot and Cursor are planned, not built yet.

Only the time you were actually there counts.

Writing prompts, reading replies, steering the agent: that's engaged time. A terminal left open overnight isn't.

An agent on its own earns nothing

Kick off a long task and go get lunch. The clock stops when you do.

Two sessions on one project count once

Running agents side by side doesn't double your hours.

Junk prompts get skipped

Prompts that don't reflect real work aren't counted. Your report lists them as SKIPPED, so you can see what was left out.

Your prompt text is never stored

teardrop keeps times and counts. Your chat logs leave your computer only if you run teardrop submit and confirm.

Getting started

  1. Install

    Paste the command above into a terminal. It picks the right build for your computer.

  2. Answer setup's questions

    The installer runs teardrop setup. It lists the tools it found and changes nothing without asking.

  3. Code as usual

    Run teardrop for your timeline, teardrop -l to keep it on screen, or teardrop dashboard for charts in your browser.

Questions people ask

Is it really free?

Yep. teardrop is open source under AGPLv3, and there is no paid plan.

Do I need an account?

Nope. teardrop and teardrop dashboard run from your own computer. Sign in only if you want every computer's hours in one place.

Does it read my prompts?

It scores each prompt in memory to tell real work from noise, then keeps only the counts. The text is never stored, printed, or synced. More on privacy.

What about time I spend testing?

Clicking through your app or writing up feedback isn't counted here. Record that with Lapse. Reviewers take off any overlap, so nothing counts twice.

Can someone just edit their numbers?

Every sync and export is signed, and the website refuses a report that was edited. A signature alone can't prove the hours are real, so for hours that count, teardrop submit lets the server check them against the chat logs behind them.

I use Cursor or Copilot. Does it work?

Not yet. A VS Code extension is planned. Follow along on GitHub.

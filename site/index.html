See how much time you actually spend coding with AI.

helios reads the logs Claude Code and Codex already write, and small hooks and plugins cover Amp, Copilot, Cursor, and OpenCode. It adds up the time you were really there, with no timer to start.

Getting started

  1. Install

    Paste the command above into a terminal. It picks the right build for your computer.

  2. Answer setup's questions

    The installer runs helios setup. It lists the tools it found and changes nothing without asking.

  3. Code as usual

    Run helios for your timeline, helios -l to keep it on screen, or helios dashboard for charts in your browser.

  4. See it on the web

    Sign in to the dashboard, run the command it shows, and type the code it prints. Every computer's hours then show up live, with a public profile and a badge for your README.

Questions people ask

Is it really free?

Yep. helios is open source under AGPLv3, and there is no paid plan.

Do I need an account?

Nope. helios and helios dashboard run on your own computer. Sign in on the website only if you want every computer's hours in one place, live, with a public profile and a badge for your README. How that works.

Does it read my prompts?

It scores each prompt in memory to tell real work from noise, then keeps only the counts. The text is never stored, printed, or synced. More on privacy.

Can someone just edit their numbers?

Every sync and export is signed, and the website refuses a report that was edited. A signature alone can't prove the hours are real, so the site marks time as witnessed only when its records reached the site as it happened. Time sent later is kept apart, as unwitnessed.

I use Copilot, Cursor, or OpenCode. Does it work?

Yes. helios setup adds hooks for GitHub Copilot (the CLI and VS Code's agent) and Cursor, and a plugin for OpenCode. helios can't read their past sessions, so time counts from then on. Restart Cursor once to load its hooks. More on Copilot and Cursor.

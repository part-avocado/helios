Track the time you actually spend building with AI

teardrop reads the logs your AI coding tools already write and counts only the time you were engaged: writing prompts, reading replies, and steering the agent. An agent left running alone earns nothing.

curl -fsSL https://raw.githubusercontent.com/part-avocado/teardrop/main/install.sh | sh
curl -fsSL https://raw.githubusercontent.com/part-avocado/teardrop/main/install.sh | sh
irm https://raw.githubusercontent.com/part-avocado/teardrop/main/install.ps1 | iex

No admin rights needed. The installer checks the download's checksum, adds teardrop to your PATH, and runs teardrop setup.

Get started See the dashboard

Set up in three steps

Nothing needs to stay running in the background, and nothing changes in your AI tools without asking.

Install

Run the one-line installer above. It picks the right build for your computer, including old 32-bit Windows laptops.

Run setup

teardrop setup finds Claude Code, Codex, and Amp, keeps your history from being deleted, and offers hooks for real-time capture.

Code as usual

Run teardrop for a timeline in your terminal, or teardrop dashboard for live charts in your browser.

Hours that mean something

Most time trackers count how long a window was open. teardrop counts how long you were involved.

  • Prompts and reading earn up to 5 minutes before each prompt.
  • Watching the agent earns up to 10 minutes after each prompt.
  • Parallel sessions on one project count once.
  • Gibberish, going in circles (the same request a third time), and autopilot (a third “continue” or “fix it” in a row) earn no time.

Works with the tools you use

teardrop reads each tool's own logs, and adds hooks or plugins where logs aren't enough.

Built to be trusted

🔒

Private by default

Only counts are synced: time, prompts, tokens, and lines. Your chats leave your machine only when you submit a project for review.

🪶

Light

One small binary with no runtime to install. Hooks take about 15 ms, so Claude Code stays fast on a 10-year-old laptop.

🧱

Hard to break

Corrupt, huge, half-written, or compressed logs are handled. One bad file never stops a report.

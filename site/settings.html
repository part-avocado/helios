Set up a computer

Do this on each computer you code on. They all add up on your dashboard.

Sync key

If your sync key gets out, make a new one. The old key stops working, so run the new connect command on each of your computers afterwards.

Computers

Every computer that syncs to your account, and when it last did.

Upload a stats file

For a computer that can't reach this site. Everywhere else, set up syncing and you never need this.

  1. Make the file

    On that computer, run:

    teardrop export -o stats.json

  2. Upload it within 7 days

The file holds times and counts, never the text of your prompts. A file that was edited after it was made is refused.
